Any HTTP client can call the endpoints: they take and return JSON. The [details](/digging-deeper/details) and the [OpenAPI document](/digging-deeper/openapi) describe each resource, so you can generate a typed client from the document with the OpenAPI generator of your stack.

## Flutter

:::note
This is a **community package**, not an official integration. It is maintained independently by [xefi](https://github.com/xefi).
:::

The [`laravel_rest_api_flutter`](https://pub.dev/packages/laravel_rest_api_flutter) package provides a typed integration between a Flutter app and a Laravel Rest API backend: search, mutate, actions, delete, restore and force delete, with typed responses and gates.

```bash
flutter pub add laravel_rest_api_flutter
```

The full documentation is available at [xefi.github.io/laravel-rest-api-flutter-doc](https://xefi.github.io/laravel-rest-api-flutter-doc/).

:::warning
The package was written for Laravel Rest API 2.x. Version 3.0 changes some payloads and responses: the answers of `gates` are objects with `allowed` and `message`, the details answer a thin base extended with `with`, and actions answer `result` next to `impacted`. Check the version of the package against your backend before you rely on these parts. See the [Upgrade guide](/getting-started/upgrade-guide).
:::
