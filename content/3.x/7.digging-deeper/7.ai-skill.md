The package ships a skill for [Laravel Boost](https://laravel.com/docs/boost): a `SKILL.md` file that a coding agent loads when it works on your resources, controllers, actions and metrics, or writes client payloads for the endpoints.

## Installing the skill

Install Laravel Boost in your application, then run its installer:

```bash
composer require laravel/boost --dev
php artisan boost:install
```

Select skills during the installation. Boost finds the skill of each installed package that ships one: the package skill is named `laravel-rest-api`, in `vendor/lomkit/laravel-rest-api/resources/boost/skills/laravel-rest-api/SKILL.md`.

Run `boost:update` after you update the package, so that the agent reads the skill of the installed version:

```bash
php artisan boost:update
```

You can run it after each `composer update`:

```json
{
  "scripts": {
    "post-update-cmd": [
      "@php artisan boost:update --ansi"
    ]
  }
}
```

## What the skill covers

The agent loads the skill when a task touches the `Lomkit\Rest\` namespace, the `Rest` facade, the `rest:*` commands, or the `app/Rest/Resources` and `app/Rest/Controllers` directories. It describes:

- the resource, the controller and `Rest::resource()`, with the routes of each endpoint;
- the payloads of `search`, `mutate`, actions and metrics, with their limits and the exact form of their entries;
- typed fields, relations, scopes, instructions, the text search and the search engines;
- the authorization model: the checks before validation, the row checks, gates and the decision cache;
- the OpenAPI document, Precognition and the Artisan commands;
- the conventions to keep: declare what you expose, prefer an action or an instruction to a controller method, keep the perimeter of the base resource.

## Overriding the skill

To change what the agent reads, create `.ai/skills/laravel-rest-api/SKILL.md` in your application. Boost uses your version instead of the package one when you run `boost:update`. Add the conventions of your application there, such as the base classes and the perimeter rules of your resources.
