Laravel Rest Api turns Eloquent models into a complete JSON API. A resource declares the fields, relations, scopes, actions and metrics to expose; one route line registers the details, search, mutate, action, metric and delete endpoints. Your Laravel policies apply at every level, and Scramble documents every endpoint in OpenAPI.
